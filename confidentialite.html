Règles de confidentialité

Dernière mise à jour : 26 octobre 2026.

Ces règles concernent le site Le Vrai Fait et l'application interne « Le Vrai Fait Publication », utilisée uniquement par la chaîne Le Vrai Fait pour publier ses propres vidéos.

Utilisation des services d'API YouTube

« Le Vrai Fait Publication » utilise les services d'API YouTube. En utilisant cet outil, vous acceptez les Conditions d'utilisation de YouTube. Les données sont traitées conformément aux Règles de confidentialité de Google.

Données collectées

Le site ne collecte aucune donnée : pas de formulaire, pas de compte, pas de cookie, pas de statistiques.

L'application ne collecte aucune donnée sur les spectateurs ni sur d'autres utilisateurs. Elle n'utilise que les comptes de la chaîne, avec l'autorisation explicite de leur titulaire :

  • YouTube Data API : envoyer les vidéos de la chaîne, régler leur date de publication et vérifier leur état (titre, statut, lien) ;
  • Gmail API (envoi seulement) : envoyer un rapport de publication à l'adresse de la chaîne elle-même ; l'application ne lit aucun e-mail ;
  • API Meta (Facebook, Instagram) et API TikTok : publier les vidéos sur les comptes de la chaîne.

Stockage, partage et conservation

Les jetons d'accès et les informations de publication (identifiant et lien de chaque vidéo publiée) sont stockés uniquement sur l'ordinateur de la chaîne. Ils ne sont ni partagés, ni vendus, ni transmis à des tiers, et ne servent qu'à la publication décrite ci-dessus. Les informations obtenues via les API YouTube sont conservées au plus 30 jours, puis supprimées ou actualisées. Aucun cookie n'est déposé.

L'utilisation des informations reçues des API Google respecte les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Révocation et suppression

L'accès peut être retiré à tout moment depuis la page des autorisations du compte Google ou depuis les paramètres de chaque plateforme. Après révocation, les jetons et les données stockées sont supprimés de l'ordinateur sous 7 jours. Une demande de suppression peut aussi être faite via les messages privés de la chaîne.

Contact

Via les messages privés de la chaîne sur Instagram ou Facebook.

Privacy Policy (English)

Last updated: October 26, 2026. This policy covers the Le Vrai Fait website and the internal tool "Le Vrai Fait Publication", used only by the Le Vrai Fait channel to publish its own videos.

Use of YouTube API Services

"Le Vrai Fait Publication" uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. Data is handled in accordance with the Google Privacy Policy.

Data accessed and how it is used

The tool only accesses the channel's own accounts, with the account owner's explicit consent: YouTube Data API (upload the channel's videos, set their publish date and check their status), Gmail API (send-only: a publishing report to the channel's own address; no email is read), Meta and TikTok APIs (publish the channel's videos). No data about viewers or any other user is collected. The website sets no cookies and collects no data.

Storage, sharing and retention

Access tokens and publishing records (ID and link of each uploaded video) are stored only on the channel's computer. They are never shared with, sold or transferred to third parties. Data obtained from YouTube API Services is kept for at most 30 days, then deleted or refreshed. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and deletion

Access can be revoked at any time via the Google security settings page or each platform's settings. After revocation, tokens and stored data are deleted from the computer within 7 days. Deletion requests can also be sent through the channel's direct messages (Instagram, Facebook).
